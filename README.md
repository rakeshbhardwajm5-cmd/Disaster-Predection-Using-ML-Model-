# Disaster Management System Using a Pre-Trained ML Model

- This project develops a disaster management system using a pre-trained machine learning model.

- The ML model is trained to analyze readings from locally connected sensors and predict possible disaster situations.

- A pre-configured monitoring device will be installed in homes and buildings located near disaster-prone areas.

- The device will continuously collect data from connected sensors, such as environmental or safety-related readings.

- When the sensor readings exceed predefined safety limits, the ML model will analyze the data and identify potential risks.

- If a possible disaster is detected, the system will activate a built-in alarm to alert people nearby.

- The device will also send warning signals to locally connected mobile phones and other alert systems.

- The main purpose of this project is to provide early warnings and help people take action before a disaster occurs.

- This system is designed to support disaster preparedness, safety, and emergency response.
